# Response to review round 1

Disposition of every point in `review-round-1.md` (Codex, reviewing `fb4f49f`). The spec, plan and tickets are revised to draft v2 in the same commit. Nothing here approves a value, a run or a budget; all remain `needs-triage`.

Summary: 20 adopted (some qualified), 2 questions answered. The largest design changes are (a) rehearsals use only calibration rows and non-cohort generation items; (b) neuron attribution no longer materializes z in the backward pass — it reuses the stored per-token gradient ∂M/∂c_t and recomputes z in a forward-only pass, which removes the memory problem in point 16; (c) the proxies are renamed and redefined (trace log-likelihood with target alignment; stop pull on stop tokens only, before the last content line); (d) the statistics have explicit per-arm gates, paired contrasts, an equivalence margin and Holm families, and say what is lost when a gate fails.

3. **Adopt.** Provenance is carried per arm from the `sequences-v2` leakage record: online-grpo is `partial` (frozen plan not local); every statement says "no overlap with available sources", never "clean" or "not training questions". 4. **Adopt.** Exact equation (spec §Metrics): for content target positions T_e = {t : token t is a response-content token}, trace log-likelihood is mean over t ∈ T_e of log p_θ(x_t | x_<t), read from logits at t−1. This includes the first content token (predicted from the header's last position) and excludes `<|im_end|>`, the trailing newline, prompt and padding. Base traces are stored as the generated token IDs and stop reasons; teacher forcing uses those exact IDs (prompt IDs + generated continuation), never a re-tokenized decode. A hand-computed fixture with distinct per-position values is in 02.

5. **Adopt, with a simpler definition.** The `####` component is dropped (its context-dependent tokenization and absence in prose answers made it ill-defined). **Stop pull** = mean over prefix positions t of log Σ_{s ∈ S} p_θ(s | x_≤t), with S = the tokenizer's generation stop IDs actually used by the pilot decoder (recorded in 01; at least `<|im_end|>` and `<|endoftext|>`), over positions whose next target token lies before the start of the response's last non-empty line (token offsets; a token crossing that newline counts as inside the last line). Rows with an empty set are excluded from stop-pull analyses with a recorded reason; coverage is reported; an empty mean is never zero. It is a proxy for early termination, not an expected length; its direction is checked against generation length in the predeclared concordance analysis (point 22).

6. **Adopt.** Both attribution sums run over every unpadded position (prompt, header and response) at which the branch is active, not only metric positions. 03 adds a fixture where an adapter affects the loss only through an earlier prompt token, checked against an independently applied gate finite difference.

7. **Adopt.** Verified against the pinned `peft==0.18.0` (`requirements-pilot2.txt`): the scaled branch is inline. The gate is a forward hook on each `lora_B` module that returns `g · out` (in the graph, g = 1 by default). Because Δy = s · out, ⟨∂M/∂Δy, Δy⟩ = ⟨∂M/∂out, out⟩, so the attribution is scale-free and needs no reconstruction. Checks added: hook-gate equivalence with an explicit scaled-branch gate on a fixture with s ≠ 1; active routing and frozen parameters after every `set_adapter`; zero and disabled branches; wrong-branch and wrong-layer mutations; real-model finite differences in 06b.

8. **Adopt.** Matched controls are defined per target, sampled without replacement from an eligible population that excludes every adapter in that arm's frozen top-10 sets for both metrics; same module type; write size within ±20% of the target's discovery write; seeded; ties by (layer, module). Group controls are the union of the per-target matches for that metric's top 10, so module counts match. A target with no eligible match is recorded unavailable and dropped from the paired single comparison (no loosening); a group with any unavailable member is unavailable. Stage D now has one matched group per metric where it is used: gold-sft gets both (5 runs), online-grpo gets the trace-likelihood pair (3 runs), plus a new untuned reference (9 runs total). The gate no longer assumes 60 points.

9. **Adopt.** The gate is per arm and metric: for the 5 top singles and 5 matched singles, report Spearman, sign agreement, the median absolute error and the slope of real on predicted effect, with paired question bootstrap intervals; the pooled figure is a summary only. Predictions for confirmation are the discovery mean attribution (fixed; no re-estimation). Group predictions are the sum of member attributions, labelled first-order. Finite differences (06b) test wiring; single and group zeroing test the nonlocal approximation; both are reported and neither substitutes for the other. Pass rule per arm × metric: real effect has the predicted sign for ≥ 4 of 5 top singles and for the top-10 group **[proposed]**; the other diagnostics are reported, not gated.

10. **Adopt.** If an arm × metric fails the gate: primary 2's cross-arm comparisons involving that arm and metric are reported as unvalidated and exploratory (Stage C cannot rebuild a 196-vector); primary 1 is limited to the directly measured Stage C/D contrasts for gold-sft; primary 3 is limited to the directly measured 64-neuron intervention, and attribution concentration is described as "attribution", not causal sparsity. This holds for primary 3 regardless of the gate.

11. **Adopt.** Primary 1 contrasts (gold-sft, confirmation, paired by question): Δ_len(L) − Δ_len(match_L) and Δ_trace(L) − Δ_trace(match_L) for the stop-pull top-10 set L; the same pair for the trace-likelihood set A. Support requires (i) stop-pull removal of L beyond its control with the interval excluding 0, and (ii) |Δ_trace(L) − Δ_trace(match_L)| ≤ 0.25 · |Δ_trace(A) − Δ_trace(match_A)| with the whole 95% interval of the ratio's numerator inside that margin **[proposed margin]**. Contradicted if (i) holds and the trace effect of L exceeds the margin with its interval outside it. Anything else is inconclusive. Stage D (gold-sft) is a separate behavioural check: length and early-stop changes for L vs match_L, and v3 accuracy changes, with capped and invalid outputs counted as their own outcomes; it can confirm or fail to confirm, not rescue, the teacher-forced result. Ranking statistics (ρ, top-10 overlap) are reported as descriptive.

12. **Adopt.** Spearman on signed mean attribution vectors (average ranks for ties); arms with any unresolved module excluded from primary 2 and listed. Paired question bootstrap (10,000, percentile intervals) of correlation *differences*: (a) ρ(online, offline) − ρ(gold, online), (b) ρ(online, offline) − ρ(gold, offline) — support needs both > 0; (c) ρ(k0, gold) − ρ(k2, gold), (d) ρ(k2, gold) − ρ(k5, gold) — ordering needs both > 0. Primary family = {primary 1's two contrasts, primary 2's four differences, primary 3's per-arm retained-effect contrasts} per metric, Holm-adjusted at α = 0.05; everything else exploratory. All of this is sealed with the selection freeze.

13. **Adopt.** The primary sparse condition is the natural 64-term read without rescaling; the rescaled read is moved to the deferred list. Retained effect R = (M_sparse − M_removed) / (M_full − M_removed) per arm and metric on confirmation questions, with M_removed from full removal of that top `down_proj` adapter (always measured, added to Stage C). R is unavailable when |M_full − M_removed| is below a resolution floor (the 95% bootstrap interval of the denominator includes 0) or non-finite. Neurons are ordered by signed attribution in the direction of the adapter's own effect (largest contributions to its predicted removal effect first); term-size and random subsets use the same size and rules.

14. **Adopt.** Concentration and cancellation are unavailable (not sparse or dense) when the total |attr| or the signed sum is below a resolution floor set from the batch-invariance measurement in 06b. The null is accumulation in a uniformly random neuron order (1,000 seeded orders), giving the expected fraction of total |attr| reached by m neurons; the "shuffled index" wording is removed.

15. **Adopt.** TF32 is removed from this pass: everything is FP32 (decision deferred; the compute is small enough). Generation batch policy: 06b compares batch 1 with candidate batch sizes on 20 calibration-disjoint generation items through the full 1,024-token cap, longest prompts first, measuring KV-cache peak. A batch size qualifies only if v3 correctness flips ≤ 1/20 and stop-reason changes ≤ 1/20 **[proposed]**; otherwise the next smaller size is tried; batch 1 always qualifies. The batch manifest is frozen. The study generates a new full-arm and a new untuned reference under that batching (the untuned threshold is recomputed, not reused); item-level differences from the pilot results are reported.

16. **Adopt; my estimate was wrong.** Materializing z for 28 layers at 16k tokens is ~15.3 GiB, not ~4 GB. Redesign: the attribution backward stores only the scalar g_t = ∂M/∂c_t per token, layer and metric (tiny); a second, forward-only pass recomputes z per layer and contracts attr_j = −a_j Σ_t z_{j,t} g_t, one layer at a time. Exactness is preserved because z does not depend on the backward. Cost per arm: 2 forwards + 2 backwards. The sweep starts at 2k padded tokens, includes singleton and longest-example probes, benchmarks the real two-backward + recompute + write path, records failed candidates, recovers from OOM by aborting that candidate only, and stops 06b if no candidate meets the memory policy.
