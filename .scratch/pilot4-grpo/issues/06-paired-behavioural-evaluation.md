# 06: Evaluate greedy and sampled behaviour with the paired gate

**What to build:** Evaluate verified GRPO checkpoints on the existing held-out
cohort and report behavioural changes under the two approved decoding modes.

**Blocked by:** 05 — Train and resume the complete 64-step GRPO arm.

**Status:** resolved

- [x] Generate 750 greedy responses across five checkpoints and 2,400 sampled
      responses at checkpoints 0/64, on the identical 150 items with frozen
      prompts/cap, draw IDs, batch membership, sampling policy and seeds.
- [x] Save each response and both scorers' decisions, generated token length,
      ending/cap flags and exact config/runtime/adapter provenance.
- [x] Reuse verified completed items/draws and reject incompatible resume;
      do not duplicate draws or treat a live PID as successful completion.
- [x] Report strict/flexible accuracy, invalid/cap rates, length distributions
      and paired checkpoint changes. Sampled accuracy is average draw reward,
      not pass-at-eight; correlated draws remain clustered by item.
- [x] Compute the preregistered paired interval for zero-minus-final greedy
      accuracy and distinguish passing non-inferiority, demonstrated harm and
      inconclusive evidence without equating a failed gate to damage.
- [x] Use 10,000 paired item-bootstrap resamples, seed 42, for greedy and
      sampled drops: each selected problem carries both checkpoints' complete
      draw records; report the 2.5th/97.5th percentiles and save resampling IDs.
- [x] Explain sampled-decoding uncertainty and shared-seed limits; preserve
      resampling identities and the single-training-seed limitation. The item
      bootstrap does not isolate repeated-decoding uncertainty on this exact
      cohort and is not a training-seed interval.
- [x] Offline tests verify pairing, scorer identity, exact known intervals,
      missing draws, corruption, completed reuse and CPU-only report generation.
- [x] Guided notebook stages display the outcomes and evidence rather than
      hiding them behind a historical aggregate accuracy check.
