# Use frozen pilot cohorts under a versioned evaluation protocol

The earlier SPAR baseline numbers lack the exact prompts, item lists, and scorer settings needed for an identical reproduction, so pilot 1 will establish a new versioned protocol and treat those numbers as reference results rather than acceptance gates. It will freeze 150 GSM8K test items and a subject-balanced MMLU cohort of 20 test items from each of 57 subjects using seed 42, reusing those item IDs across baseline and adapter variants to support paired comparisons within a single-GPU budget. The smaller cohorts trade full-benchmark comparability for feasible, auditable runs: reports will identify the sampled protocol, include a 95% within-subject sampling range for MMLU, and avoid presenting its score as a full-test MMLU result.
