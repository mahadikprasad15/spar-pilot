# Domain Docs

This is a single-context repo. Engineering skills read `CONTEXT.md` at the repo root and relevant ADRs in `docs/adr/` before exploring the affected area.

If either is absent, proceed. The domain-modeling skill creates them when terms or decisions are resolved.

Use terms from the `CONTEXT.md` glossary in issues, proposals, hypotheses, and tests. If a needed term is missing, reconsider the wording or note the gap for domain modeling.

Surface any conflict with an existing ADR explicitly.

## Layout

- `CONTEXT.md`: root domain context and glossary.
- `docs/adr/`: decisions for this repo.
