Deep dive 1

What is the model doing in a forward pass?

Teacher forcing means supplying the predetermined question and gold solution tokens. A causal model processes preceding context at each position; we inspect hidden outputs. We do not choose the next token, sample an answer, compute an SFT loss or update parameters.

Decoder block output

One transformer layer’s output, before the final model normalization after layer 27. It already reflects changes from earlier layers.

Δhℓ,t = hadaptedℓ,t − huntunedℓ,t

Direct linear-module contribution

The module’s own LoRA branch evaluated on its adapted-pass input x. Its ordinary denominator is also evaluated on that same x, including frozen bias if present.

d(x) = (α/r) B A x
r = 1, α = 1 → d(x) = (aᵀx)b

PEFT’s A is a row direction and B a column direction at rank 1. This product defines a weight update, but Pilot 3’s principal measurements concern its outputs on actual tokens. The scalar aᵀx depends on the input; downstream block changes also involve nonlinear operations and upstream effects.

Instrument checks · section 7

Why validate a quantity we already know how to calculate?

A forward hook could point to the wrong position; an adapter could be attached to the wrong projection; a checkpoint switch could contaminate the reference. Correct arithmetic does not rule these out. These gates check the connected measurement instrument.

GateExpected identityWhat a failure could mean
A · initializationCheckpoint 0 changes and direct contributions are exactly zero on counted positionsNonzero initialization, incorrect switching or unpaired reference
B · identityFrozen base hashes match; checkpoints, input masks and hooks match their recorded identitiesWrong source, mutated base, different tokens or wrong hook
C · rank-1 contributionLoRA branch equals its scaled A/B product on the same module input; post-addition subtraction agrees within the fixed policyWrong sign/scale/module mapping or numerical disagreement
Pre-addition threshold per coordinate:
  1e−6 + 1e−5 × |expected direct contribution|

Post-addition subtraction adds a rounding allowance:
  4 × ε32 × (|adapted output| + |ordinary output|)
  ε32 = 2^−23

These are fixed engineering acceptance thresholds, not guaranteed error bounds. Floating-point subtraction can obscure small contributions between large outputs; the direct branch is checked separately. Saved below-resolution fractions describe sampled validation coordinates. They are not a count of all scientific tokens. Gate A remains exact: these tolerances do not excuse a nonzero initial write.

Deep dive 2

Tokens in the context ≠ tokens in the statistic

A mask is a boolean array aligned to the input token IDs. True means count this position in a particular view. The entire sequence still enters the model, so solutions are contextualized by the question and prior gold tokens.

System text, instructions, control tokens, padding and ambiguous boundary tokens are excluded from the aggregates. Offsets and token identities are saved so content ownership can be audited. We retain complete gold solutions; cutting them to match FineWeb would change the scientific inputs.

Deep dive 4

Parallel examples, sequential adapters

The GPU processes E examples together in each forward pass. We load one model and switch its saved adapter checkpoints sequentially. The untuned reference is shared only after disabled-adapter invariance checks; it is not a second full model.

For batch size 8, 300 examples form 38 ordered batches. There are 38 × 5 = 190 batch/checkpoint combinations to seal. Main forward work is 38 × (1 + 5) = 228 passes, plus validation overhead. A fully completed batch needs no further model work; a partial batch re-creates its reference and verifies it before processing missing checkpoints.

Deep dive 5 · toy example

Why averaging order changes the answer

Imagine two examples. Every token in example A has a one-dimensional change of +1; every token in B has −1. Baseline magnitude is 2 per token. A has one token. Change B’s length to see the distinction.

Token weighting · primary block ratio

Equal-example weighting · primary block ratio0.000

Average within each example, then average +1 and −1 equally: they cancel.

The mean change magnitude stays 1, while the magnitude of the mean change can be 0. The primary block scalar uses the latter. Both are retained because direction cancellation is scientifically relevant.

Block: ‖weighted mean Δh‖ / weighted mean ‖huntuned‖
Module: weighted mean ‖d(x)‖ / weighted mean ‖ordinary(x)‖

The secondary module mean-per-token ratio is another statistic: average only tokens with nonzero ordinary magnitude; equal-example weighting averages each example’s defined ratios before averaging eligible examples. Ratio of means still includes individually zero-denominator tokens and is undefined only when its aggregate denominator is zero. We add no epsilon.

This slider explains a mathematical choice. It does not modify the notebook, its cohorts or its frozen execution.

Deep dive 6

What does the CPU bootstrap resample?

For each draw, select example IDs with replacement, combine their sufficient sums using the requested weighting, then recompute the nonlinear ratio. Do not bootstrap individual tokens or average already calculated ratios.

The same GSM8K ID draw is used across question/solution, checkpoints, layers and projection types; FineWeb draws are independent. Seed 42 and 2,000 replicates are fixed. Percentile 95% intervals use defined replicates and report how many are undefined. These intervals do not include variation across training seeds.

Deep dive 8

Why “completed” has three meanings

1. Process exited

The child’s return code says whether the command ended successfully. An interrupted notebook cell may leave this child alive.

2. Status says completed

A mutable JSON snapshot can be stale or mid-write. It helps monitoring but cannot certify payloads.

3. Evidence is verified

The verifier reconstructs the expected combinations, checks markers/hashes, validates shapes/counts/hooks/gates and compares aggregate sums. This is the scientific gate.

After section 11 succeeds and no child is active, the GPU can be disconnected. CPU report reconnect: 1 → 2 if needed / restart → 3 → 4 → 11 → 12 → 13, with CPU_REPORT_ONLY=True and unchanged names.

OOM, incompatible identity and corrupt marked payloads require diagnosis. Do not quietly change batch size, precision, thresholds or input lengths within a named execution.
